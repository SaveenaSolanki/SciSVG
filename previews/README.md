# previews/

Generated PNG/WebP previews, produced by:

```bash
python scripts/generate_previews.py            # PNG 512px
python scripts/generate_previews.py --size 1024 --format png --format webp
```

These are **build artifacts** — the canonical source is `assets/**`. This
directory is gitignored and regenerated by CI/release builds, so do not commit
previews by hand.
